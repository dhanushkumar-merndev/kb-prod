# Legacy reference

`legacy-crm.html` is retained only to compare Khana Banao’s recognizable visual language:
navy gradient rails, saffron accents, compact KPI cards and tables, status tags, booking
dockets, shift clock panels, charts and empty states.

The copied file was sanitized on 2026-07-23:

- the embedded Supabase project URL was replaced with a redacted marker;
- the embedded publishable key was replaced with a redacted marker.

Do not import, serve, execute or extend this file. Its localStorage fallback, shared JSON
records, browser password hashing, first-visitor bootstrap, embedded credentials and
browser-side provider calls are explicitly outside the production architecture.
